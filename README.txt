UNIPATH PUBLIC PILOT
====================

This is a static, responsive prototype. It can be deployed to Vercel, Netlify,
or GitHub Pages without a build step.

IMPORTANT:
- Programme records are fictional examples.
- No live university, scholarship, tuition, deadline, immigration, or work-rule data is connected.
- The profile form is local-only and does not submit or store personal data.
- Do not describe this as a live admissions or scholarship database.

DEPLOY WITH VERCEL:
1. Create a GitHub repository and upload index.html and this README.
2. Sign in to Vercel using your own account.
3. Choose Add New -> Project and import the repository.
4. Framework preset: Other. Build command: leave blank. Output directory: leave blank or use ./ .
5. Deploy. Vercel will provide a public vercel.app URL.
6. Test the site on mobile and desktop before sharing.

Before using a custom domain or collecting student data, add a privacy notice,
security review, real official-source records, and a process for updating them.
